## Summary
- New `dockguard ui`: a live terminal dashboard showing the drive, whether it's safe to eject, and every managed app's state.
- Docker Desktop's state is now read in under a second when it's stopped, instead of about 16 seconds.

## Highlights
- **Dashboard:** drive usage, an eject line that names whatever still blocks the eject, and every target refreshed every 3 seconds.
- **Coloured results:** check output in the dashboard shows `[ok]` in green, `[fail]` in red and `[skip]` in amber.
- **Keys run the same code as the commands:** `s` start, `x` stop, `c` check, `E` stop everything and eject. Stopping and ejecting ask you to confirm, and a confirmation is always its own key press.
- **Faster probes:** `dockguard list` with Docker stopped went from about 16 seconds to under 1 second, because Docker is confirmed stopped from the process list when none of its processes runs.

## Behaviour changes
- When no process from `Docker.app` is running, Docker Desktop is reported `stopped` without calling `docker desktop status`. If any Docker Desktop process runs, or the process check fails, the CLI is still asked.

## Notes
- The dashboard needs a terminal. In scripts, keep using `dockguard list` and `dockguard status`.
- Built with Bubble Tea and Lip Gloss; still builds with Go 1.23.
